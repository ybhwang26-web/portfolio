01

Writing equations

Inline math sits in a sentence: the bolt load is $F_b = F_i + C\,P$ while the joint stays clamped. Display math gets its own line:

$$C = \frac{k_b}{k_b + k_p}, \qquad F_c = F_i - (1-C)\,P$$

In the file, that equation is written as plain TeX:

<div class="eq math">$$C = \frac{k_b}{k_b + k_p}, \qquad F_c = F_i - (1-C)\,P$$</div>
02

A stepped animation

Each step builds on the last, the way a 3Blue1Brown video adds one idea at a time. Press Next to play the next step, or Replay all. This demo shows a point going around a circle tracing out a sine wave.

The scene is a list of steps, each with a label, a duration and a draw function:

Scene.create(document.getElementById("demoScene"), {
  viewBox: "0 0 720 320",
  steps: [
    { label: "Draw the axes", dur: 900,
      draw: (g, t, S) => S.line(g, 40, 160, 680, 160, { write: t, muted: true }) },
    { label: "Draw the circle", dur: 1200,
      draw: (g, t, S) => S.circle(g, 150, 160, 100, { write: t }) },
    // ...one entry per idea
  ]
});
03

How to add a new project

  1. Copy this file and rename it, e.g. swirl-injector.html. All files sit together in one folder.
  2. Change the title, date and tags at the top.
  3. Write sections with <section>, equations in TeX, and scenes with Scene.create.
  4. Add a card for it on index.html: copy the existing <a class="item"> block and change the link and text.

Accent color

The whole site uses one accent color. To change it, edit --accent and --accent-text in site.css (there is one value for light mode and one for dark mode).
